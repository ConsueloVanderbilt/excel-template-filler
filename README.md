# Excel 多数据源模板填充工具

这是一个完全在浏览器本地运行的单页工具。它把多份原始表作为统一数据池，通过一组匹配字段寻找记录，再按多组字段映射将数据填入一个目标模板。文件不会上传。

## 文件结构

```text
excel-row-sorter/
├── index.html                 页面结构与中文文案
├── styles.css                页面样式与移动端适配
├── app.js                    文件解析、映射、匹配、填充和导出逻辑
├── vendor/
│   └── xlsx.full.min.js      本地版 SheetJS Excel 处理库
└── README.md                  使用、测试和修改说明
```

## 本地运行

打开 `excel-row-sorter` 文件夹，双击 `index.html`。建议使用最新版 Chrome、Edge 或 Safari。无需安装、登录或联网。

## 使用方法

1. 一次选择多个 `.xlsx`、`.xls` 或 `.et` 原始数据文件，之后也可以继续追加。
2. 检查每个文件的解析状态、工作表、数据行数和表头行数；失败文件不会影响其他文件。
3. 上传一个目标模板文件，并检查模板表头行数。
4. 选择原始数据池匹配字段和模板匹配字段。
5. 在“填充映射”中设置一组或多组 `原始字段 → 模板字段`。
6. 点击“添加一组填充映射”可以继续增加，最多 20 组；不需要的映射可以删除。
7. 点击“开始匹配并填充”，检查总统计、各映射统计和字段级预览。
8. 点击“导出填写后的 Excel”。

## 多组填充映射

- 匹配字段仍然只有一组，填充映射可以有 1～20 组。
- 每组都必须同时选择原始来源字段和模板目标字段。
- 同一个模板目标字段不能被两组映射重复使用。
- 同一个原始来源字段可以重复使用，并写入不同模板字段。
- 每个字段独立执行多来源解析。同一企业的营业收入可以来自文件 A，利润总额可以来自文件 B。
- 某个字段发生数据冲突，只阻止该字段写入，不影响同一对象的其他字段。

## 多文件字段规则

- 每个原始文件单独解析表头、合并单元格和真实列位置。
- 字段通过完整表头路径识别，例如 `经营情况 > 2026年 > 营业收入`。
- 字段选择器优先显示所有成功文件都存在的字段；部分文件才有的字段会显示 `仅 X/N`。
- 同一字段在不同文件中可以位于不同列，读取时会分别寻找真实列号。

## 多来源取值规则

每一个填充映射都会独立执行以下规则：

- 没有匹配记录：标记“未匹配”。
- 所有候选来源值为空：标记“来源数据为空”，不修改模板。
- 多条记录中只有一个非空值：自动使用，标记“已填充（自动选择唯一有值来源）”。
- 多条非空记录基础等价：自动使用，标记“已填充（多来源一致）”。
- 多条非空记录值不同：标记“数据冲突”，显示每个来源和值，不修改该字段。
- 单条匹配且来源非空：标记“已填充”。

空值包括 `undefined`、`null`、空字符串和纯空格字符串。数字 `0`、字符串 `"0"`、布尔值 `false` 都是有效数据。

## ET 文件说明

- `.et` 是 WPS 表格格式，工具不会假定它一定等同于 `.xlsx`。
- 上传后会实际调用 SheetJS 尝试读取；可以读取时正常进入现有流程。
- 无法读取时，文件列表会明确提示“请在 WPS 中另存为 XLSX 后重新上传”，浏览器 Console 会记录真实错误原因。
- 工具不保证所有 ET 文件都能读取。ET 模板即使可以读取，导出结果也会保存为 `.xlsx`。

## 统计说明

结果区显示：

- 原始文件数量和原始数据总行数
- 匹配对象数量
- 填充映射数量
- 理论填充单元格数量
- 成功填充数量
- 单一来源、自动选择唯一非空和多来源一致数量
- 未匹配对象数量
- 所有来源为空和数据冲突的字段数量

同时会按每一组映射分别显示成功、为空、冲突和未匹配数量。预览表以“匹配值 × 填充映射”为一行，展示最终值、状态和来源。

## 模板保真说明

程序直接修改目标模板原 workbook，不使用 JSON 重建简化表格。它会尽量保留工作表顺序、其他工作表、合并区域、列宽、行高、未指定单元格和已有内容。

SheetJS 社区版无法保证所有高级样式、图表、宏、外部链接、数据验证或复杂 Excel 对象在重新保存后完全不变。复杂模板请使用副本测试。`.xlsm` 会尝试保留 VBA，`.xls` 和 `.et` 模板会导出为 `.xlsx`。

## 建议测试清单

1. **多组映射**：同时设置营业收入、利润、资产和人数，确认一次处理写入多个目标列。
2. **字段独立来源**：文件 A 只有营业收入，文件 B 只有利润，确认两个字段分别取自不同文件。
3. **局部冲突**：营业收入多来源一致、利润值冲突，确认只填写营业收入。
4. **重复目标**：两组映射选择同一模板字段，确认执行前被拦截。
5. **映射增删**：添加多组后删除中间一组，确认编号和选择正常。
6. **ET 可读取文件**：确认正常解析并参与匹配。
7. **ET 不可读取文件**：确认显示另存为 XLSX 的提示，其他文件仍可使用。
8. **不同列位置**：同一字段在文件 A 和文件 B 位于不同列，确认都能读取。
9. **唯一非空与多来源一致**：分别验证自动选择规则。
10. **所有来源为空、0 和 false**：确认空值判断正确。
11. **缺少字段与未匹配**：确认只影响相应文件、对象或映射。
12. **模板完整性**：比较导出前后的工作表、合并区域、列宽、行高和非目标单元格。

## 零基础修改指南

- 修改文字：打开 `index.html`，搜索原文字后替换。
- 修改颜色：打开 `styles.css`，修改顶部 `:root` 中的颜色值。
- 修改映射上限：打开 `app.js`，搜索 `MAX_MAPPINGS = 20`。
- 修改预览数量：打开 `app.js`，搜索 `slice(0, 300)`。
- 修改前请复制整个文件夹备份；不要修改 `vendor/xlsx.full.min.js`。

主要函数均在 `app.js` 中并带有中文注释：`parseWorkbook()`、`parseSourceFiles()`、`parseMergedHeaders()`、`buildColumnDefinitions()`、`getSharedSourceFields()`、`buildGlobalMatchIndex()`、`resolveSourceField()`、`validateFieldMappings()`、`resolveFieldValue()`、`fillTemplateFields()`、`fillTemplate()`、`exportWorkbook()`。
