# Excel 多数据源模板填充工具（V1.2）

这是一个完全在浏览器本地运行的单页工具。它把多份原始 Excel 作为统一数据池，通过匹配字段寻找唯一记录，再将指定数据填入一个目标模板 Excel。文件不会上传。

## 文件结构

```text
excel-row-sorter/
├── index.html                 页面结构与中文文案
├── styles.css                页面样式与移动端适配
├── app.js                    多文件解析、索引、填充、预览和导出逻辑
├── vendor/
│   └── xlsx.full.min.js      本地版 SheetJS Excel 处理库
└── README.md                  使用、测试和修改说明
```

## 本地运行

打开 `excel-row-sorter` 文件夹，双击 `index.html`。建议使用最新版 Chrome、Edge 或 Safari。无需安装、登录或联网。

## 使用方法

1. 在“原始数据文件”区域一次选择多个 Excel；之后也可以继续追加。
2. 查看文件列表。每个文件会显示解析状态、工作表名称、数据行数、字段数和表头行数。
3. 如果某个文件的字段识别不正确，单独调整该文件的“表头”行数；不需要的文件可点击“移除”。
4. 上传一个目标模板文件，并检查模板表头行数。
5. 选择原始数据池匹配字段和模板匹配字段。
6. 选择原始数据来源字段和模板目标字段。
7. 点击“开始匹配并填充”，检查统计、数据来源和逐行状态。
8. 点击“导出填写后的 Excel”。

## 多文件字段规则

- 每个原始文件单独解析表头、合并单元格和真实列位置。
- 字段通过完整表头路径识别，例如 `经营情况 > 2026年 > 营业收入`。
- 原始字段下拉框优先显示所有成功文件都存在的字段。
- 部分文件才有的字段也会显示，例如 `营业收入 [仅 3/4 个文件]`。
- 同一字段在文件 A 可以位于 B 列，在文件 B 可以位于 G 列；读取时会分别查找真实列号。
- 单个文件解析失败只会标记该文件，不影响其他成功文件。

## 匹配与多来源取值规则

- 只做格式化显示值的完全一致匹配，不做模糊匹配或自动纠错。
- 系统逻辑上建立跨文件索引，不会真的把原始 Excel 合并成新文件。
- 每条索引记录保留文件名、工作表名和 Excel 行号。
- “重复出现”本身不再视为错误。系统会读取所有匹配记录的当前来源字段，再按下面顺序判断。
- 没有匹配记录：标记“未匹配”。
- 所有匹配记录的来源字段都为空：标记“来源数据为空”，不修改模板。
- 多条匹配记录中只有一个非空值：自动使用，标记“已填充（自动选择唯一有值来源）”。
- 多条非空记录的值基础等价：自动使用，标记“已填充（多来源一致）”。例如数字 `1000` 与字符串 `"1000"` 可视为一致。
- 多条非空记录的值不同：标记“数据冲突”，展示每个来源及其值，不修改模板。
- 单条匹配且来源非空：标记“已填充”。
- 模板匹配字段为空：跳过并标记“匹配字段为空”。
- 缺少所选来源字段的文件会显示全局提示；该文件对应候选按空值处理。

空值包括 `undefined`、`null`、空字符串和纯空格字符串。数字 `0`、字符串 `"0"`、布尔值 `false` 都是有效数据。

## 统计说明

结果区显示：

- 成功参与处理的原始文件数量
- 原始数据总行数
- 模板待匹配行数
- 成功填充单元格数
- 单一来源填充数量
- 自动选择唯一非空来源数量
- 多来源一致数量
- 未匹配行数
- 所有来源为空数量
- 数据冲突数量

每个原始文件的独立行数会一直显示在上传文件列表中。

## 模板保真说明

程序直接修改目标模板原 workbook，不用 JSON 重建简化表格。它会尽量保留工作表顺序、其他工作表、合并区域、列宽、行高、未指定单元格和已有内容。

本项目使用 SheetJS 社区版。社区版无法保证所有高级样式、图表、宏、外部链接、数据验证或复杂 Excel 对象在重新保存后完全不变。复杂模板请使用副本测试。`.xlsm` 会尝试保留 VBA，普通 `.xls` 会导出为 `.xlsx`。

## 建议测试清单

1. **不同列位置**：文件 A 的营业收入放 B 列，文件 B 放 G 列，确认都能正确填写。
2. **共同与部分字段**：确认下拉框显示 `全部 N/N` 或 `仅 X/N`。
3. **跨文件唯一匹配**：模板企业分别来自不同文件，确认来源文件正确。
4. **重复但唯一非空**：多个文件含同一企业，只有一个营业收入有值，确认自动采用该值。
5. **多来源一致**：两个文件分别填写数字 `1000` 和字符串 `"1000"`，确认自动填写。
6. **真正冲突**：两个文件分别填写 `1000` 和 `1200`，确认不填写并显示两个来源和值。
7. **所有来源为空**：多条匹配记录均为空，确认不视为冲突且不填写。
8. **0 和 false**：确认数字 `0`、字符串 `"0"` 和布尔值 `false` 不会被当作空值。
9. **缺少字段**：确认缺字段文件不影响其他文件处理，并显示提示。
10. **未匹配和模板空值**：分别检查状态与统计。
11. **解析失败**：拖入损坏文件，确认只标记该文件失败。
12. **模板完整性**：比较导出前后的工作表、合并区域、列宽、行高和非目标单元格。

## 零基础修改指南

- 修改文字：打开 `index.html`，搜索原文字后替换。
- 修改颜色：打开 `styles.css`，修改顶部 `:root` 中的颜色值；`--green` 是主色。
- 修改预览数量：打开 `app.js`，搜索 `slice(0, 100)`，把 `100` 改为需要的数量。
- 修改最多表头层数：在 `app.js` 中搜索 `Math.min(8`，同步修改相关数字。
- 修改前请复制整个文件夹备份；不要修改 `vendor/xlsx.full.min.js`。

主要函数均在 `app.js` 中并带有中文注释：`parseWorkbook()`、`parseSourceFiles()`、`parseMergedHeaders()`、`buildColumnDefinitions()`、`getSharedSourceFields()`、`buildGlobalMatchIndex()`、`resolveSourceField()`、`isEmptyValue()`、`normalizeComparableValue()`、`resolveMatchedValue()`、`fillTemplate()`、`exportWorkbook()`。
